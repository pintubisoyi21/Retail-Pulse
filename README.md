## 🎯 Project Overview

RetailPulse is a production-grade, AI-powered analytics platform built on the **Online Retail dataset (541,909 transactions, 4,372 customers, 38 countries)**. It delivers:

| Module | Description | Target Metric |
|--------|-------------|---------------|
| 🔍 Customer Segmentation | RFM + K-Means + DBSCAN (6 segments) | Silhouette ≥ 0.35 |
| 📈 Demand Forecasting | Prophet + LSTM Hybrid Ensemble | MAPE ≤ 12% |
| ⚠️ Churn Prediction | XGBoost + SHAP Explainability | AUC-ROC ≥ 0.88 |
| 📦 Inventory Optimization | EOQ + Safety Stock + ABC Analysis | Reduce stockout 30–50% |
| 🖥️ Interactive Dashboard | Streamlit multi-page app | Load < 8s |

## 🚀 Quick Start

### 1. Clone & Install
```bash
git clone https://github.com/your-username/retailpulse.git
cd retailpulse
pip install -r requirements.txt
```

### 2. Add Your Data
```bash
cp /path/to/Online_Retail.xlsx data/
```

### 3. Run Pipeline (in order)
```bash
cd notebooks
python Week1_Day1_2_EDA_Cleaning.py
python Week1_Day3_Segmentation.py
python Week1_Day4_5_Forecasting_Prep_Prophet.py
python Week1_Day6_LSTM.py
python Week2_Day8_Hybrid_Forecast.py
python Week2_Day9_Churn_XGBoost.py
python Week2_Day10_Inventory_Optimization.py
python Week2_Day11_12_Tuning_Drift.py
```

### 4. Launch Dashboard
```bash
streamlit run src/dashboard/app.py
```

### 5. Docker (all-in-one)
```bash
docker-compose up --build
# Dashboard → http://localhost:8501
# MLflow    → http://localhost:5000
```

## 🔄 MLOps Pipeline

```
Daily Batch Job (Airflow/Cron)
    │
    ├─ [1] Data Validation (Great Expectations)
    ├─ [2] Feature Engineering
    ├─ [3] Drift Detection (Evidently AI)
    │        ├─ Drift detected? → trigger retraining
    │        └─ No drift?       → skip retraining
    ├─ [4] Model Retraining (if needed)
    │        └─ Compare AUC: new > old → promote
    └─ [5] Log to MLflow + update dashboard
```
